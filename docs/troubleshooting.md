# 문제 해결

먼저 로그인한 Tutor-T의 `https://tutor-t.thinkforbl.com/courses/<숫자>` 페이지인지 확인하고, 영상 강의를 선택한 뒤 목차를 펼쳐 **Start**를 누르세요. 사용자 스크립트와 확장을 동시에 실행하지 마세요.

## 제어 패널이 나타나지 않음

- 스크립트 또는 확장이 활성화되어 있고 Tutor-T 사이트 접근이 허용되어 있는지 확인하세요. 다른 사이트와 숫자가 아닌 과정 주소는 지원하지 않습니다.
- Tampermonkey 5.3+를 Chrome 계열에서 쓰면 확장 설정의 **Allow User Scripts**(Chrome 138+) 또는 **Developer Mode**를 켜야 합니다. [공식 안내](https://www.tampermonkey.net/faq.php?locale=en&q=Q209)
- Safari에서는 매니저 앱 설치 외에 Safari 확장 활성화와 Tutor-T 웹사이트 접근 허용도 필요합니다. Userscripts 팝업에서 해당 스크립트의 설치·활성화 상태를 확인하세요. [Userscripts 안내](https://github.com/quoid/userscripts)
- 새로 설치하거나 업데이트했다면 강의 페이지를 새로고침한 뒤 **Start**를 다시 누르세요. Firefox 임시 확장은 브라우저 재시작 후 다시 설치해야 합니다.
- Aside에서 사용자 스크립트 매니저를 설치할 수 있는지는 아직 확인되지 않았습니다. 기존 Aside CLI의 동작 확인을 새 설치 경로의 지원으로 해석하지 마세요.

## 시작했지만 영상이 재생되지 않음

브라우저의 자동 재생·소리 권한 때문에 `play()`가 거절될 수 있습니다. 사이트 영상의 재생 버튼을 직접 한 번 누르고 재생 위치가 증가하는지 확인하세요. 필요한 경우 브라우저 설정에서 Tutor-T의 자동 재생을 허용하세요. 기기를 깨운 상태로 강의 탭을 열어 두어야 합니다.

직접 일시정지한 영상은 자동으로 재개하지 않습니다. 계속 보려면 영상의 재생 버튼으로 재개하세요. **Stop**은 자동 제어를 중단하는 용도이며, 영상 자체의 일시정지는 사이트 재생 버튼으로 처리하세요.

제한 시간이 끝났거나 선택한 과정 밖으로 이동했다면 올바른 과정으로 돌아와 **Start**를 다시 누르세요. 새로고침·탭 종료 후에도 다시 시작해야 합니다.

## 영상이 끝났는데 다음 강의로 이동하지 않음

1. 주 영상이 실제로 끝났는지 확인하세요. 재생 위치만 끝부분에 있거나 보충영상이 끝난 상태는 주 영상 종료와 다릅니다.
2. 보충영상이 끝났다면 사이트가 본 강의로 자동 복귀할 시간을 주세요. 끝났다는 문구만 남은 보충영상을 다시 시작하지 마세요.
3. 목차를 펼치고 **Next**가 표시되며 활성화되어 있는지 확인하세요. 비활성화된 버튼이나 알 수 없는 화면에서는 기다립니다.
4. 사이트 완료 체크 표시가 없으면 실제 종료 뒤 3초를 기다립니다. 그 뒤 정상 **Next**가 가능하면 이동합니다. 체크 표시를 만들거나 완료 기록을 수정하지 않습니다.
5. 영상 로딩·네트워크 오류나 사이트 화면 변경이 있으면 자동 제어를 멈추고 화면을 확인하세요. 새로고침했다면 **Start**를 다시 누르세요.

사이트의 다음 버튼을 따라 `1.1.4 → 1.2 → 1.2.1`처럼 주제·하위 강의·챕터 사이를 이동합니다. 재생이 끝난 플로팅 플레이어가 다음 버튼을 가리면 잠시 숨겨 이동하고 표시 상태를 복원할 수 있습니다.

## 질문·보충설명 화면에서 대기함

보충영상은 실제로 재생하고 끝날 때까지 기다립니다. 상호작용 건너뛰기 설정을 켜면 인식된 정상 **Skip / Continue / Return** 버튼을 사용할 수 있습니다. 설정이 꺼져 있거나 인식할 수 없는 화면에서는 직접 진행해야 할 수 있습니다. 답안을 작성·제출하거나 임의 버튼으로 진행하지 않습니다.

100% 모드에서는 사이트가 완료로 표시한 텍스트 강의도 로딩을 위한 3초 대기 후 다음 항목으로 이동합니다. 완료 표시가 없는 텍스트 강의나 지원하는 주 영상을 찾을 수 없는 화면에서는 대기할 수 있습니다. 내용을 확인한 뒤 정상 UI로 진행하세요. 수동 탐색 중 자동 동작을 원치 않으면 먼저 **Stop**을 누르세요.

## 다음 강의로 갔지만 수강 완료 표시가 없음

영상 재생 종료와 사이트의 완료 저장은 별개입니다. `recent_actions`의 `advanced` 기록에서 `completion_recorded: false`는 이동 당시 완료 표시가 없었다는 뜻입니다. `true`도 당시 표시를 확인했다는 의미이며 전체 과정의 수료 인증을 증명하지 않습니다.

시간 제한 모드의 `finished`는 재생 순회 종료를 나타냅니다. 기본 **100%까지 실행** 모드에서는 마지막 영상 뒤에도 미완료 항목을 다시 재생하며, 사이트 완료율이 실제 100%가 되면 `course_completed`로 종료합니다. 별도의 시험·수료증 발급 여부는 사이트에서 확인하세요. 이 도구는 재생 위치·속도 변경, 가짜 종료 이벤트, 완료 API 호출, 답안 제출로 기록을 보정하지 않습니다.

## 100% 모드에서 계속 대기함

- `waiting_for_progress`: 사이트 완료율을 읽을 수 없습니다. 커리큘럼 패널을 여세요.
- `waiting_for_course_completion`: 목차 항목에는 완료 표시가 있지만 사이트의 과정 완료율이 아직 100%가 아닙니다. 사이트 저장·네트워크 상태나 별도 필수 항목을 확인하세요.
- 미완료로 남는 영상은 실제로 다시 재생합니다. 저장 실패나 필수 입력이 있으면 같은 항목이 다시 나타날 수 있으며, 정답이나 완료 기록을 만들어 진행하지 않습니다.
- 100% 모드에는 12시간 제한이 없습니다. **Stop**, 탭 종료·새로고침, 과정 밖으로 이동하면 재시작이 필요합니다. 브라우저가 꺼졌거나 기기가 잠들면 실행을 유지할 수 없습니다.

## 브라우저마다 결과가 다름

설치 가능한 매니저와 영상 코덱·자동 재생 정책은 브라우저 및 운영체제마다 다릅니다. Firefox 임시 확장은 재시작 시 제거되고, WebKit 테스트 결과는 실제 Safari 설치·재생 검증과 다릅니다. 현재 확인 범위는 [호환성 표](compatibility.md)를 참고하세요.

문제를 보고할 때는 브라우저·운영체제 버전, 설치 방식과 매니저 버전, 패널 상태, 어떤 동작에서 멈췄는지 포함하세요. 비밀번호, 쿠키, 인증 토큰, 개인 수강 기록이나 강의 영상은 첨부하지 마세요.
